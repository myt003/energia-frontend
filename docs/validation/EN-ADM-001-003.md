# EN-ADM-001/003 validation — Administrator invoice scan and confirmation

## Build under review

- App version: **0.6.0+9**
- Channel: Administrator mobile
- Stories: invoice capture plus mandatory extracted-field review
- API: `https://steam-little-holland-thread.trycloudflare.com/api/v1`
- Temporary AI provider: Groq `qwen/qwen3.8-27b`

This APK uses the administrator demo account and the same application ID as the
staff build. Installing it updates the existing app; synchronized staff data
remains in PostgreSQL.

## Main workflow

1. Install and open the admin APK.
2. Confirm the charcoal/sand/electric-blue **Administrator capture** workspace.
3. Confirm the status bar says **Administrator data synchronized**.
4. Tap **Scan energy invoice**.
5. Confirm North Plant is locked as the destination.
6. Select **Electricity bill · Standard** and supplier **NorthGrid Energy**.
7. Add one or more pages with Camera or Gallery.
8. In the native crop screen, crop and rotate each page before accepting it.
9. Optionally rotate/remove pages in Energia; maximum five pages.
10. Tap **Extract draft fields** and wait for AI + OCR processing.
11. Review every field and confidence/provenance marker.
12. Change at least one value, for example energy quantity from `1250` to
    `1251`.
13. Tap **Confirm official invoice**.
14. Expected: only this explicit confirmation creates the official Invoice row.

## Classroom demo bill

For a camera-free test:

1. Tap **Use classroom demo bill** in the capture screen.
2. Submit the bundled invoice page.
3. Expected extracted values:
   - Account: `CLASSROOM-001`
   - Period: `2026-10-01` to `2026-10-31`
   - Energy: `1250 kWh`
   - Maximum demand: `82.5 kW`
   - Total: `320.50 USD`
   - Tariff: `EDU-1`
4. The public API already contains one live classroom draft in **Drafts**, so it
   can also be opened directly for review.

## Administrator verification

Open `https://steam-little-holland-thread.trycloudflare.com/admin/` with:

- Username: `energia-admin`
- Password: `Energia-Admin-Demo-2026!`

Inspect:

- Invoice schemas
- Invoice scans and page quality flags
- AI jobs
- Model request logs
- Official invoices
- Audit events

Before mobile confirmation, the scan must exist only as a draft and no official
Invoice should be inserted. After confirmation, raw extraction and corrected
values must both remain auditable.

## Acceptance checklist

- [ ] Role-based startup opens administrator mobile instead of staff tasks
- [ ] Palette remains charcoal/sand/electric blue
- [ ] Site, supplier, and invoice schema are selected before capture
- [ ] Camera/gallery supports up to five pages
- [ ] Pages can be cropped and rotated on device
- [ ] Backend stores checksums, image quality flags, and OCR text
- [ ] AI maps fields only against the selected schema
- [ ] Low-confidence and missing fields are visibly reviewable
- [ ] Duplicate billing periods produce a warning/block
- [ ] Consumption and monetary fields require manual confirmation
- [ ] Corrections do not overwrite the retained raw extraction
- [ ] Official Invoice is created only after confirmation
- [ ] Mobile, Django Admin, and PostgreSQL show the same synchronized state
